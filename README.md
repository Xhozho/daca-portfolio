# DACA | Data Analytics Portfolio

## About This Portfolio

This portfolio documents my work from the **Data Analyst Career Accelerator (DACA)**, using the UrbanStyle.ltd case study to explore business problems and practise applying data analysis techniques.

Across Weeks 0–9, I've used SQL, Python, Pandas, and Power BI to investigate data-quality issues, analyse sales and customer behaviour, build dashboards, and develop data-processing functions.

Each weekly folder contains my work, including queries, code, visualisations, findings, and lessons learned. For team projects, I've also documented my individual contributions and included links to our shared work.
